Πρόγραμμα ηχογράφησης

Όλες οι ώρες είναι ώρα Ελλάδας. Αν η λήξη είναι πριν την έναρξη (π.χ. 22:00–03:00), η ηχογράφηση περνά τα μεσάνυχτα. Κανόνες που επικαλύπτονται ενώνονται σε μία ηχογράφηση.

Οι επόμενες 7 ημέρες

Ποιότητα ήχου

Ισχύει από την επόμενη ηχογράφηση. Πάνω από την ποιότητα που εκπέμπει ο σταθμός δεν κερδίζεις τίποτα. Για ομιλία το mono στα 64–96 kbps είναι αρκετό. Το stereo στον ίδιο ρυθμό μοιράζει τα bits σε δύο κανάλια.

Χώρος αποθήκευσης

(0 = χωρίς όριο· όταν ξεπεραστεί, σβήνονται οι παλαιότερες)

Οι ηχογραφήσεις αποθηκεύονται στο GitHub (Releases του αποθετηρίου), όχι στη Vercel ούτε σε δική σου συσκευή. Το GitHub δεν βάζει συνολικό όριο χώρου, μόνο έως 2 GB ανά αρχείο (κάθε κομμάτι είναι λίγα MB). Πάνω από ~100 GB το GitHub μπορεί να το θεωρήσει υπερβολική χρήση. Η σημερινή και η χθεσινή ημέρα δεν σβήνονται ποτέ αυτόματα.

Εκτιμήσεις

Κατανάλωση

Η ηχογράφηση τρέχει σε servers του GitHub (GitHub Actions), που χρεώνει τα λεπτά που μένει ανοιχτός ο server. Επειδή το αποθετήριο είναι δημόσιο, τα λεπτά είναι απεριόριστα και δωρεάν. Κάθε εκτέλεση ζει έως 6 ώρες, οπότε μια μεγάλη ηχογράφηση συνεχίζεται αυτόματα από την επόμενη, με κενό περίπου ενός λεπτού.
